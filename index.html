Six streams, one cascade

Networking, systems, cloud, data and automation — each skill feeding into the next.

Networking

CCNA

Routing & switching, subnetting, VLANs and the protocols that move traffic — the foundation on the way to CCNP.

Systems

Linux

Shell scripting, file systems, permissions and process management — the command line as a daily tool, not a last resort.

Cloud

AWS

EC2, S3, VPC and IAM — building and securing infrastructure that runs somewhere other than a single machine.

Data

SQL

Queries, joins and schema design, applied to databases that live in the cloud rather than on a laptop.

Automation

DevOps

CI/CD pipelines, infrastructure as code and monitoring — closing the loop between writing software and running it.

Scripting

Python

The glue between all of the above — automation scripts, data handling and quick tools that save an afternoon of clicking.
